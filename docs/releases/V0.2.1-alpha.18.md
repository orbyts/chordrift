# Chordrift v0.2.1-alpha.18

This daily-driver checkpoint repairs interrupted direct-move convergence found
while moving five tracks from Rasa Archive to Cinema Monsoon.

One Spotify gesture can produce a removal and an addition row in the detailed
maintenance plan. Chordrift now collapses matching rows into one logical move
before it creates or edits a proposal. Exact duplicates are harmless;
conflicting inferred destinations stop before any state change.

An interrupted run may leave a complete editable copy of the approved model.
Tracks that are both current in Spotify and represented in that copy remain
already covered; they are not new intake. Historical assignment revisions also
cannot re-add a track while an active exclusion exists.

The live incident was recovered entirely in Neon. The five moves were recorded,
provider-authored order was accepted only after exact membership equality, and
the final approved model contains 1,429 represented tracks with zero pending
maintenance operations and zero direct-intake items. No Spotify request or
provider write was used for recovery.

V021-06 remains in progress. Alpha.18 is an installable local daily-driver
repair, not the `v0.2.1-beta.1` hosted web/remote-CLI release.
