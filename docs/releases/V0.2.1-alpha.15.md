# Chordrift v0.2.1-alpha.15

Alpha.15 completes V021-04: typed service commands, operation progress,
cancellation, retries, and recovery can survive service or worker restarts.

## What changed

- A command and its exact account/subject-scoped idempotent receipt are committed
  before a worker may execute it.
- An identical replay after timeout or restart returns the original receipt;
  the same key with different intent fails closed.
- Concurrent workers claim through exclusive expiring PostgreSQL leases. Long
  operations heartbeat explicitly, and stale workers cannot append progress or
  completion after recovery.
- Every queued, running, progress, recoverable, failed, completed, or cancelled
  transition is an immutable operation-local event for cursor-based reconnect.
- Retryable failures and abandoned leases use a bounded persisted attempt budget.
  Exhausted work becomes a terminal client-safe failure.
- Cancellation is durable: queued work stops immediately, running work stops at
  a cooperative worker checkpoint, and terminal work reports `too_late`.
- The capability manifest adds `service.durable-operations.v1`. Application
  contract 1.2 and product-session schema 1 remain unchanged.

## Database boundary

Additive migration 0050 creates the current operation ledger and append-only
event stream. Command payloads are typed application DTOs—not shell commands,
SQL, arbitrary URLs, provider credentials, or encryption keys.

Migration 0050 was rehearsed on disposable PostgreSQL and was not applied to the
personal Neon database. Local maintenance continues to require only migration
0047, so `47/50` with three hosted migrations pending is expected.

## Install

```console
$ cargo install chordrift --version 0.2.1-alpha.15 --locked --force
```

The ordinary local daily-driver command remains:

```console
$ scripts/chordrift-maintain.sh --account personal
```

Alpha.15 does not move that CLI to the hosted service. V021-05 owns authenticated
remote CLI parity while retaining an explicit local development transport.
V021-06 owns hosting selection and deployment verification.

This release did not contact Spotify, access the personal Neon project, or
apply migration 0050.
