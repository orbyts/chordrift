# Chordrift v0.2.1-beta.7

Beta.7 completes the portable two-login boundary for the installed remote CLI.

`service session login` authorizes the machine to the user's Chordrift account
through Auth0. `service provider spotify connect` separately opens hosted
Spotify consent and waits until the account-scoped provider view confirms that
the encrypted server-side credential is ready. The CLI never receives a Neon
credential or a Spotify refresh token.

The browser can begin either flow without an existing Chordrift cookie: Auth0
returns only to the validated internal continuation. CLI-initiated Spotify
consent finishes on a clear browser page while the terminal observes readiness
through the same typed provider-connection query used by other clients.
