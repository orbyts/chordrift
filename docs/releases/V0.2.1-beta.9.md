# Chordrift v0.2.1-beta.9

Beta.9 makes the installed remote CLI a complete ordinary-maintenance daily
driver alongside the hosted web interface. Both clients serialize application
contract 1.6 DTOs and use the same Rust-owned interpretation, durable operation,
authorization, provider-write, and verification paths.

The new `chordrift service maintenance wizard` starts or resumes a durable
maintenance session, follows progress, accepts server recommendations without
turning them into implicit consent, collects only unresolved placement and
Liked Songs decisions, presents the exact provider effects, and defaults every
provider authorization to no. Raw maintenance commands remain available for
diagnostics and automation.

Remote CLI inspection now covers both Chordrift and provider library views,
playlist tracks, track evidence, Excluded tracks, and comparison reports.
Spotify disconnect is also a typed durable command shared by web and CLI; it
revokes the encrypted hosted credential while preserving Chordrift history and
intent.

Release validation includes strict Clippy, the full Rust and PostgreSQL-backed
CI suites, thin-client scripted wizard tests, authenticated transport parity,
and synthetic single/composite/delayed provider workflows.
