# Chordrift v0.2.1-beta.6

Beta.6 removes browser-to-localhost navigation from the critical CLI login
path.

The installed CLI still creates an expiring PKCE verifier and opens a one-time
authenticated consent page. After approval, the browser now displays a clear
success page and the CLI learns that approval completed through a bounded
status poll. The returned code remains useless without the verifier held only
by the initiating CLI, and the existing one-time exchange creates the separate
revocable product session.

Older loopback clients remain compatible. The new path works when Safari or a
privacy boundary refuses an HTTPS-to-`127.0.0.1` navigation. It also prevents a
consumed approval form from becoming a downloaded empty response during the
normal flow.
