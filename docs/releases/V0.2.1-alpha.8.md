# Chordrift v0.2.1-alpha.8

This prerelease repairs the order-only stop encountered after direct intake
expanded Celluloid Mehfil to seven tracks.

## Repair

- When current Spotify and approved proposal memberships are exactly equal but
  ordered differently, ordinary maintenance accepts the observed Spotify order
  into a new editable proposal.
- The new `proposals align-provider-order` operation refuses missing, extra, or
  duplicate memberships before changing any position.
- This is a Neon-only intent update. The wizard does not execute
  `reorder_playlist` and makes no Spotify membership write.
- Scripts require `maintenance.provider-order-intent.v1`, preventing the
  alpha.8 workflow from running against alpha.7.

## Recover the interrupted run

Do not move or re-add the tracks. Install alpha.8 and rerun maintenance:

```console
$ cargo install chordrift --version 0.2.1-alpha.8 --locked --force
$ rehash
$ scripts/chordrift-maintain.sh --account personal
```

Chordrift prepares an editable copy, prints `Accepting current Spotify order:
Celluloid Mehfil`, approves the carried model/artwork, and should finish with an
empty provider plan.
