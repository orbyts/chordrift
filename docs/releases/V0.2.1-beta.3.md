# Chordrift v0.2.1-beta.3

Beta.3 repairs the interactive remote-CLI login experience discovered during
the beta.2 acceptance run.

## Fixed

- Interactive terminals now display and flush the authorization URL before the
  CLI begins its bounded callback wait.
- `chordrift service session login --no-open` prints the URL without launching
  the default browser, allowing the user to choose another trusted browser.
- Browser consent remains authenticated, explicit, one-time, PKCE-bound,
  expiring, loopback-only, and independently revocable.

Google Safe Browsing reputation is an external deployment concern. Chordrift
does not encourage bypassing its warning; the hostname must be submitted for
false-positive review separately.
