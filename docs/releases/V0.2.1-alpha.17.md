# Chordrift v0.2.1-alpha.17

This checkpoint completes V021-05 remote CLI parity. The installed CLI now has
an authenticated HTTPS transport over the same compatibility, command, and
query DTOs used by the Rust authority, plus an explicit in-process development
transport implementing the identical trait.

The CLI stores only an opaque Chordrift product session in the operating-system
credential store. It accepts the session through bounded standard input, never
prints it, zeroizes temporary bearer memory, negotiates compatibility before
work, and refuses non-loopback plaintext HTTP. Typed structured errors are the
only server failures presented to the client.

No service is deployed by this release. V021-06 still owns hosting, external
product authentication, service URL distribution, observability,
backup/restore, worker operations, and release rehearsal. The existing local
daily-driver workflow remains available while that gate is pending. No personal
Spotify or Neon operation and no migration was required for V021-05.
