# Chordrift v0.2.1-alpha.7

This prerelease repairs the artwork carry-forward failure encountered during
the first alpha.6 direct managed-playlist intake.

## Repair

- Ordinary maintenance now carries forward all 25 approved Drift Atlas v5
  covers. It no longer uses the obsolete 20-cover v4 manifest.
- A track present in a managed destination remains
  `direct_managed_addition` while its revised proposal is still `proposed`.
  Therefore a run interrupted after assignment safely resumes on the next
  invocation instead of leaving an unapproved draft hidden as already covered.
- The script requires `maintenance.artwork-carry-forward.v1` so the repaired
  workflow cannot run against an alpha.6 binary.

## Recover the interrupted run

Do not repeat the Spotify Add. Install alpha.7 and rerun ordinary maintenance:

```console
$ cargo install chordrift --version 0.2.1-alpha.7 --locked --force
$ rehash
$ scripts/chordrift-maintain.sh --account personal
```

Chordrift reuses the recorded assignment, approves the complete revised model,
imports the unchanged 25-cover system for that proposal, and rebuilds the plan.
No Spotify membership write is required for the already-present track.
