# Chordrift v0.2.1-alpha.1

Released 2026-08-29 as the first stabilization prerelease for the v0.2.1 local
CLI daily driver.

## What changes

- `scripts/chordrift-maintain.sh --account personal` is the single ordinary
  workflow for Likes, named intake, exclusions, managed edits, and direct moves
  between managed playlists.
- A direct move from one managed playlist to exactly one other managed playlist
  is reviewed as reclassification. Several possible destinations produce one
  concise question.
- The former `Re-evaluate` holding queue is retired. Its Neon history remains;
  current accounts must not recreate it.
- A separately pending retirement no longer blocks ordinary maintenance, but
  the daily wizard still cannot execute retirement.
- The binary publishes a machine-readable capability handshake, and helpers
  fail closed when `CHORDRIFT_BIN` selects an older executable.
- Ordinary additions remain enumerated and cannot replace unrelated playlist
  membership or restore manually removed tracks.

## Install

```console
$ cargo install chordrift --version 0.2.1-alpha.1 --locked --force
$ rehash
$ unset CHORDRIFT_BIN
$ chordrift capabilities --require maintenance.unified-workflow.v1
```

Load the current personal database environment in the usual operator shell,
then verify `chordrift db status` reports 47/47 migrations before maintenance.
Apogee remains local operator plumbing, not a Chordrift product dependency.

## Scope

This prerelease stabilizes the local CLI before the remaining v0.2.1 work. It
does not yet implement hosted transport, a GUI, or the separate Classification
Authority project. The existing V021-01 through V021-06 hosted-authority
sequence remains the v0.2.1 release goal; later alphas may checkpoint that work
before v0.2.1 final.
