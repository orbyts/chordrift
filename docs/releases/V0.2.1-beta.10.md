# Chordrift v0.2.1-beta.10

Beta.10 corrects the release-boundary defect found by the final beta.9
cross-client smoke. The beta.9 Rust authority advanced the shared contract to
1.6, while its embedded browser wrapper still submitted 1.5 and therefore
failed closed before maintenance became available.

The server now renders the browser contract version directly from the same
Rust `CONTRACT_VERSION` constant used by the API, worker, and remote CLI. A
regression asserts that the served JavaScript contains that exact version, so
future contract-minor changes cannot silently strand one client wrapper.

No provider observation or Spotify write occurred while discovering or fixing
the mismatch. Beta.10 otherwise carries the beta.9 remote maintenance wizard,
library inspection parity, and durable provider disconnect unchanged.
