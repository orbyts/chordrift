# Chordrift v0.2.1-beta.13

Beta.13 promotes the latest Web presentation work without changing Chordrift's
Rust-owned application contract, provider behavior, maintenance semantics, or
database schema. Web and remote CLI remain thin clients of contract 1.6, and
the hosted database remains at schema 52.

The signed-in header now presents the sanitized Auth0 display name and avatar
through an accessible account menu with a safe fallback. Account settings add a
device-local System, Light, or Dark appearance preference, and the light theme
now covers the existing maintenance, library, exclusion, activity, developer,
and settings surfaces consistently. Theme state is presentation-only and does
not enter a DTO or the server-side account model.

This release also establishes `$CRATES/chordrift` as the sole canonical local
checkout. The compact Web handoff and root agent guide direct future coding
agents to that repository and retain the established rule that every accepted
Web change is built into one exact API/worker image before hosted review.
