# Chordrift v0.2.1-beta.11

Beta.11 makes the deployed build identity visible in the Web UI. A small footer
now reports the exact `CARGO_PKG_VERSION` compiled into `chordrift-server`, so a
user can confirm that the browser is talking to the expected container binary
while iterating on Web presentation.

The Rust authority renders the version into the no-store HTML response. The
browser does not maintain a second version literal, query an unauthenticated
release service, or infer version from static-asset names. A regression requires
the delivered HTML to contain the exact Cargo version and no unresolved build
placeholder.

This release also adds a deliberately compact Web-only handoff and paste-ready
prompt for GPT-5.3 Codex Spark. Spark may polish the browser presentation and
use the existing Vortex container delivery loop, but it must not modify Rust,
DTOs, workflow meaning, provider behavior, authentication, migrations, secrets,
or deployment architecture. Rust and cross-client release work return to the
primary Chordrift task.
