# Chordrift v0.2.1-alpha.6

This prerelease makes Spotify's per-playlist **Add** action a safe, first-class
intake gesture.

## Direct managed-playlist intake

- A previously unknown track observed in exactly one managed playlist stays in
  that playlist. Chordrift does not classify it as provider drift or plan a
  removal.
- The unified maintenance wizard records the already-observed destination as
  canonical intent, approves the revised complete model, and makes no Spotify
  membership write for that track.
- Several observed managed destinations remain ambiguous and require a choice.
- An active exclusion always wins. Reusing an excluded track requires explicit
  restoration; direct placement cannot restore it silently.
- Known-track moves between managed playlists retain the alpha.2 direct-move
  behavior.

Scripts require `maintenance.direct-managed-intake.v1`, preventing an alpha.6
wizard from running against an older binary that could remove the new track.

## Use it

1. In Spotify, open the correct existing Chordrift playlist and select **Add**
   for the song.
2. Run `scripts/chordrift-maintain.sh --account personal`.
3. Chordrift reports `Detected direct intake` and records the destination. It
   asks only if the destination is genuinely ambiguous or the track is
   excluded.

## Install

```console
$ cargo install chordrift --version 0.2.1-alpha.6 --locked --force
$ rehash
$ chordrift --version
$ chordrift capabilities --require maintenance.direct-managed-intake.v1
```
