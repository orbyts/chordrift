# Chordrift v0.2.1-alpha.5

This prerelease removes the long silent pause between Spotify observation and
the ordinary-maintenance review.

## Fast bulk preview

- Immutable plan details now include track title, artists, and ordinary direct-
  move interpretation from one set-based Neon query.
- The first eight TSV columns remain unchanged for existing plan consumers.
- The wizard no longer starts `tracks inspect` once for move inference and
  again for display for every changed track.
- `Analyzing observed changes…` appears immediately after provider observation.
- Scripts require the machine-readable
  `maintenance.bulk-plan-preview.v1` capability and reject older binaries.

The exact 22-removal case reported during daily use took 108.58 seconds in the
alpha.4 review-only path. Rendering the same stored plan through the alpha.5
bulk contract took 3.06 seconds. A complete current plan and intake-audit review
finished in 8.54 seconds. These rehearsals were read-only and made no Spotify
changes.

## Scope boundary

Direct moves of already-known tracks between managed playlists remain
supported. A previously unknown track added directly to a managed playlist is
still reserved for alpha.6; until then use Liked Songs or a named intake
playlist for genuinely new music.

## Install

```console
$ cargo install chordrift --version 0.2.1-alpha.5 --locked --force
$ rehash
$ chordrift --version
$ chordrift capabilities --require maintenance.bulk-plan-preview.v1
```

This checkpoint does not change the V021-01 through V021-06 hosted-authority
goal or the intended v0.2.1 final daily-driver release.
